# 공유용 페이지

팀에 공유한 웹 페이지 두 개의 원본이다. 앱 코드가 아니라 **문서**다.

| 파일 | 무엇 |
|---|---|
| `nexar-report.template.html` | 인수인계 문서 — 수집 과정 · 데이터 구성 · 시뮬레이션 설계 · 다음 수집 후보 |
| `catalog-page.template.html` | 카탈로그 뷰어 — 28품목의 판매자·단가·수량구간을 훑는 페이지 |
| `build.py` | 스냅샷에서 데이터를 뽑아 위 템플릿에 채워 완성본을 만든다 |

## 왜 완성본이 아니라 템플릿인가

두 페이지 모두 스냅샷에서 뽑은 파생 데이터를 품는다. 뷰어는 **569KB 중 546KB**가
그 데이터다. 완성본을 그대로 커밋하면 원본(`data/nexar_snapshot.json`)과 파생본이
저장소에 함께 있게 되고, 스냅샷을 다시 뜨면 **조용히 어긋난다.**

[`docs/decisions/0002`](../decisions/0002-스냅샷은-원본을-보존하고-해석은-읽는-시점에.md)가
기각한 구조다 — 진실이 두 곳이면 어느 쪽이 맞는지 물어야 한다. 그래서 저장소에는
사람이 쓴 부분(템플릿)만 두고 데이터는 만들 때마다 뽑는다.

## 만들기

```bash
python docs/공유문서/build.py                 # docs/공유문서/build/ 에 생성
python docs/공유문서/build.py --out-dir /tmp  # 위치 지정
```

`build/` 는 산출물이라 커밋하지 않는다. 스냅샷이 바뀌면 다시 돌려서 다시 게시하면 된다.

## 게시본 (2026-09-04 스냅샷 기준)

- 인수인계 문서 — https://claude.ai/code/artifact/48b2b752-80ca-45a3-92e8-96ba28a103c8
- 카탈로그 뷰어 — https://claude.ai/code/artifact/a6e81ef9-c85d-4d9b-a02f-ef3b915c6b0a

**둘 다 기본은 비공개다.** 페이지의 공유 메뉴에서 열어야 팀이 볼 수 있다.
링크가 안 열린다는 말이 나오면 대개 이것이다.

## 고칠 때

템플릿의 `__DATA__` 자리표시자는 그대로 두고 나머지를 고친 뒤 `build.py` 를 돌린다.
게시본을 갱신하려면 같은 아티팩트 URL에 다시 올려야 한다 — 새로 올리면 별개의
페이지가 생겨서 팀이 보던 링크는 옛 내용에 머문다.
