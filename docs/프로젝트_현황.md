## 1. 프로젝트 한 줄 정의

AI 에이전트(셀러·바이어)가 자동으로 가격을 협상하고, 사람은 최종 승인만 하는 마켓플레이스의 MVP.
카탈로그는 실제 전자부품 유통 데이터(Nexar/Octopart 스냅샷)에서 읽는다.
해커톤(AWS 주최) 제출용.

**9/5~9/6 회의에서 제조업 도메인과 CRM(Odoo)이 폐기됐다** — 걷어낸 내역은
[`decisions/0005`](decisions/0005-odoo-와-제조업-도메인을-걷어낸다.md).
기획 문서 `P0_확정안_v3.md`는 그 이전 기준이라 도메인 전제가 무효다.

## 2. 아키텍처 — MMVP L0~L4 매핑

```
app/
  schemas.py    L0 — 품목/메시지타입(REQUEST·OFFER·ACCEPT·REJECT·SETTLED)/Envelope
  store.py      L1 — 거래 요약(SQLite) + 로그 파일 + 카탈로그 출처 전환(snapshot ↔ sqlite)
  agents.py     L2 — 규칙 기반 에이전트 (RuleBasedSellerAgent/RuleBasedBuyerAgent)
  llm_agents.py L2 — OpenAI 기반 에이전트 (OpenAISellerAgent/OpenAIBuyerAgent)
  audit.py      감사자 — LLM이 floor_price/cap_price 규칙을 어기면 보정
  negotiate.py  L3 — 매칭·협상 오케스트레이션, 라운드 상한(MAX_ROUNDS=3)
  report.py     L4 — 로그 기반 자연어 요약 + 리포트 파일 생성
  main.py       API 엔드포인트 + 목업(static/index.html) 서빙

  snapshot_catalog.py  커밋된 Nexar 응답을 카탈로그로 읽는 로더 (환산·합성 가정이 전부 여기)
  feasibility.py       납품 가능성 검증 (재고·최소주문량·조달납기를 룰로만 판정)
static/
  index.html    4화면 GUI 목업 (납품가능성검증/셀러등록/구매요청/협상결과·승인)
scripts/
  nexar_snapshot.py  Nexar 응답 원본을 그대로 뜨는 조회 스크립트 (평소엔 안 씀)
```

**핵심 설계 원칙**: `store.py`의 메서드 시그니처(`register_seller`, `sellers_for`, `append`, `get_log`, `set_deal`, `get_deal`)가 고정되어 있어서, 저장 방식이 바뀌어도(인메모리→SQLite→Odoo→스냅샷) 이 파일 밖은 거의 안 건드려도 됨. **Odoo를 통째로 걷어낼 때도 이 경계가 값을 했다** — `store.py` 안의 분기만 지우면 끝났고, `negotiate.py`·`report.py`는 한 줄도 안 바뀌었다. 단 하나의 예외가 MOQ로, Odoo에서 들어왔지만 스냅샷에도 있는 제약이라 `negotiate.py`의 스크리닝에 한 절로 남아 있다. `agents.py`/`llm_agents.py`도 같은 인터페이스(`SellerAgentPort`/`BuyerAgentPort`)라 `NEGOTIATOR_MODE` 환경변수 하나로 전환.

## 4. v3 확정안·흐름도 대비 — 아직 안 된 것 (우선순위순)

### 4-1. 다음 작업 후보 (구조 변경 필요, 중간 비용)
- [ ] **비교표 + 사람이 후보 중 직접 선택** — 지금은 시스템이 최저가 1건을 자동 확정 → 사람은 승인/거절만 함. v3·흐름도는 "여러 후보를 순위표로 보여주고 사람이 고른다" 구조를 요구함
- [ ] **동시 디스패치(경쟁 입찰) 구조** — 지금은 셀러 A를 끝까지 협상한 뒤 B로 순차 진행. 흐름도는 "적격 셀러 전원에게 동시 초대 → 각자 독립 제안 → 취합" 구조
- [ ] 승인 이력에 "누가" 필드 — 현재 승인자/역할 개념 자체가 없음 (정식 로그인 없이 이름 하드코딩 정도로도 P0 기준 충족 가능)

### 4-1-b. 보안 (EC2 배포 전 필수)
- [ ] **CORS·인증** — 지금 `allow_origins=["*"]` + 인증 없음이라 사용자가 방문한 아무 웹페이지의 JS가 승인/거절을 부를 수 있다. 외부 노출 전에 오리진을 좁히고 승인 계열에 토큰을 둘 것 (`app/main.py` 상단 주석 참고)

### 4-2. 인프라 (다음 마일스톤, 지금 급하지 않음)
- [ ] AWS 실배포 (Dockerfile까지는 준비됨, 실제 EC2 배포·접속 검증은 아직 안 함)
- [ ] I-03 Bedrock + Strands SDK — **현재 OpenAI API 사용 중.** 해커톤이 AWS 주최라 SDK/Bedrock 사용이 채점에 영향 줄 수 있음, 팀 확인 필요
- [ ] 4프로세스(중앙·셀러2·바이어) 실제 분리 — 지금은 한 프로세스 안에서 함수 호출로 시뮬레이션

### 4-3. 뒤로 미룬 것 (v3 문서가 스스로 P2 이상으로 명시)
- 역할 4종 분리(구매담당자/승인자/판매담당자/감사거버넌스) — 지금은 역할 구분 없음
- 정식 인증/권한 관리
- 거래상태 "정상/주의"(납기지연 등) 세분화 — 지금은 SETTLED/FAILED뿐
- VPC 3개 등 네트워크 구성 실제 구현 — 도식(발표자료)용으로만 존재

## 5. 알려진 함정 (재발 방지용)

| 상황 | 원인 | 대응 |
|---|---|---|
| `sqlalchemy.exc.OperationalError: table ... has no column named ...` | 모델에 컬럼을 **추가**했는데 기존 `data/mmvp.db`는 옛 스키마 그대로. `create_all()`은 없는 테이블만 만들지, 기존 테이블에 컬럼을 추가해주지 않음 | **컬럼을 추가할 때마다 `data/` 폴더 통째로 삭제 후 서버 재기동.** 지금 개발 단계에선 이게 제일 간단한 대응 (Alembic은 이 스코프엔 과함)<br>**컬럼 제거는 해당 없습니다** — 남은 컬럼이 nullable이면 선언에서 빠져도 무시된다. Odoo를 걷어내며 `deals`에서 3개를 뺐지만 기존 DB 그대로 돌았다([`decisions/0005`](decisions/0005-odoo-와-제조업-도메인을-걷어낸다.md)) |
| 목업 1번 화면 "등록"이 409 | `CATALOG_SOURCE=snapshot`(기본값)에서는 카탈로그의 주인이 외부(Nexar/Octopart)라 이 서비스로는 못 쓴다 | 정상 동작입니다. 셀러를 직접 등록해 보려면 `.env`에 `CATALOG_SOURCE=sqlite` 를 넣으세요 |
| `pkill -f "uvicorn app.main:app"` 로 재기동했더니 새 서버도 죽음 | pkill 패턴이 **자기 명령줄까지** 매칭해 부모 셸을 죽임 | PID를 집어서 죽이세요: `kill $(pgrep -f "[u]vicorn app.main")` |
| `ModuleNotFoundError: No module named 'app'` | `app/` 폴더 없이 `.py` 파일들이 프로젝트 루트에 바로 풀려있음 | `uvicorn app.main:app`은 "현재 폴더에 `app` 패키지가 있다"는 전제. 폴더 구조 재확인(§7 폴더구조 문서 참고) |
| 셀러가 바이어 상한가에 딱 붙여 제안함 | 상대의 유보가격을 알면 거기 붙이는 게 합리적이다. 예전엔 인터페이스가 그 값을 셀러에게 넘겼다 | 이미 제거됨. **셀러 앞으로 가는 엔벨로프·프롬프트·함수 인자에 cap_price 를 다시 넣지 말 것** (`schemas.py` 상단 규약 참고) |
| PowerShell에서 `export OPENAI_API_KEY=...` 안 먹힘 | `export`는 bash 문법, PowerShell은 `$env:`가 필요 | `.env` 파일 사용 (`.env.example` 복사 후 값 채우기) — OS/셸 무관하게 동작 |
| 목업이 AWS에서 API 호출 실패 | 예전 버전은 `const API = "http://127.0.0.1:8000/api"`로 하드코딩되어 있었음 | 이미 수정됨(`const API = "/api"` 상대경로) — `static/index.html`이 최신본인지 확인 |

## 7. 실행 방법 요약

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
# 브라우저로 http://127.0.0.1:8000/ 접속 (목업+API 같은 포트에서 서빙됨)
```

**`.env` 없이 그대로 돕니다** — 기본값이 `snapshot` 이고 스냅샷은 커밋돼 있습니다.
바꾸고 싶을 때만 `cp env.example .env` (Windows: `copy`) 후 값을 채웁니다:

```
NEGOTIATOR_MODE  rule(기본) / llm(OPENAI_API_KEY 필요, 미지정 시 gpt-4o-mini)
CATALOG_SOURCE   snapshot(기본) / sqlite
```

모델에 **컬럼을 추가**한 뒤에는 `data/` 폴더 삭제 후 재기동 (§5).
