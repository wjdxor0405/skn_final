# 결정 기록

되돌리기 어려운 결정과 그 근거를 남긴다. 코드와 명세서는 "지금 어떻게 되어 있나"를,
여기는 **"왜 그렇게 정했나 · 무엇을 검토하고 버렸나 · 대가는 무엇인가"** 를 든다.

## 규칙

- 결정이 뒤집히면 새 ADR 을 쓰고 옛것에 `상태: ADR-000N 으로 대체됨` 을 남긴다. 고치지 않는다
- **시도했다가 안 통한 대안을 반드시 적는다.** 없으면 다음 사람이 같은 순서로 같이 실패한다
- **대가를 적는다.** 대가가 없어 보이면 대안을 충분히 검토하지 않은 것이다
- 사람 이름 대신 역할로 쓴다
