## 4. 진행 중 발견해서 고친 버그

실제로 DB에 연결하고 브라우저로 눌러보지 않았으면 못 찾았을 것들입니다.

1. **`POST /session`이 이메일 토큰을 응답 본문으로 돌려주고 있었음** → 프론트는 httpOnly 쿠키(`truefit_guest`)만 읽는 게 계약이라, 카테고리 선택 화면에서 항상 404. 쿠키 발급 방식으로 수정.
2. **`config.domain_version`에 없는 컬럼(`published_at`)을 조회하는 코드** → 세션 생성 자체가 실패하는 상태였음. 실제 스키마에 맞게 수정.
3. **`plan_condition.origin`, `validation_result.severity` 등 DB CHECK 제약과 안 맞는 값**을 코드에서 쓰려다 여러 번 걸림 → 실제 허용값으로 수정.
4. **유아용품 "출산 예정"을 `null`로 표현**해서 아직 아무 답도 안 한 상태와 구분이 안 되던 버그 수정.
5. **uvicorn 개발서버 재시작 시 좀비 프로세스가 남아 옛날 코드로 계속 응답하는 문제** 발견 및 정리.
